# Voice Chat AI — Full Flow (2026-04-19)

## Architecture: Clean Architecture (4 layers)

```
interfaces → application → infrastructure → domain
```

All dependencies point inward. Domain has zero external deps; Infrastructure implements Domain ports.

---

## Full Pipeline (POST /voice-chat)

```
User Audio (base64 WAV/MP3)
   │
   ▼
┌──────────────────────┐
│  STT                 │  WhisperSTT (local, openai-whisper)
│  Speech → Text       │
└──────────┬───────────┘
           │
           ▼
        Raw Text (transcript)
           │
           ▼
┌──────────────────────┐
│  Embedding Model     │  OpenAIEmbedder / GeminiEmbedder / MiniLMEmbedder
│  Text → Vector       │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Vector Store Query  │  ChromaStore (local) or PgVectorStore (PostgreSQL)
│  top-k neighbours    │  cosine similarity, top_k=5
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  RAGService Decision │
│  Threshold Check     │  hit=0.76, ambiguity=0.65, min_margin=0.06
└────────┬─────────────┘
         │
   ┌─────┼──────────┐
   │     │          │
  HIT  CLARIFY    MISS
   │     │          │
   ▼     ▼          ▼
FAQ   Clarif.    LLM call
Answer Prompt  (OpenAI gpt-4o-mini or Gemini gemini-1.5-flash)
   │     │     + RAG context injected via system prompt
   └─────┴──────────┘
         │
         ▼
   Answer Text
         │
         ▼
┌──────────────────────┐
│  TTS                 │  ElevenLabsTTS (MP3) or GeminiTTS (WAV/PCM)
│  Text → Audio        │
└──────────┬───────────┘
           │
           ▼
        Client
{ transcript, answer, audio_b64, decision, top1_score, clarification_questions }
```

## Streaming Pipeline (GET /ws/transcribe)

Client streams binary PCM16 audio (16 kHz, mono) → Server yields `{text, is_final}` JSON events.
Provider selected via `?provider=deepgram|assemblyai` query param.

## Key Modules

### Domain (`src/voicechatai/domain/`)
- `ports/stt_port.py` — `transcribe(bytes) → str`
- `ports/tts_port.py` — `synthesize(str) → bytes`
- `ports/llm_port.py` — `generate(system_prompt, user_message) → str`
- `ports/embedder_port.py` — `embed_text(str) → list[float]`
- `ports/vector_store_port.py` — `query(vector, top_k)`, `upsert(...)`
- `ports/realtime_stt_port.py` — async streaming interface
- `entities/faq_entry.py` — `FAQEntry(faq_id, question, answer, score, metadata)`

### Application (`src/voicechatai/application/`)
- `use_cases/process_voice_chat.py` — main pipeline orchestrator
- `services/retrieval_service.py` — embed + vector store query
- `services/rag_service.py` — hit/clarify/fallback decision policy
- `services/llm_answer_service.py` — builds RAG context + calls LLM

### Infrastructure (`src/voicechatai/infrastructure/`)
- `stt/whisper_stt.py` — local OpenAI Whisper (detects raw PCM vs container)
- `stt/deepgram_stt.py` — Deepgram streaming (async, deepgram-sdk v3)
- `stt/assemblyai_stt.py` — AssemblyAI streaming (sync wrapped via thread+queue)
- `tts/elevenlabs_tts.py` — ElevenLabs MP3, default voice Rachel (21m00Tcm4TlvDq8ikWAM)
- `tts/gemini_tts.py` — Gemini WAV/PCM, voices: Kore/Charon/Fenrir/Aoede/Puck
- `llm/openai_llm.py` — OpenAI chat completions, default gpt-4o-mini
- `llm/gemini_llm.py` — Gemini generative AI, default gemini-1.5-flash
- `embedding/openai_embedder.py` — default text-embedding-3-small
- `embedding/gemini_embedder.py` — default models/text-embedding-004
- `embedding/minilm_embedder.py` — local sentence-transformers all-MiniLM-L6-v2 (384-dim)
- `vector_store/chroma_store.py` — ChromaDB persisted locally, cosine similarity
- `vector_store/pgvector_store.py` — PostgreSQL + pgvector

### Interfaces (`src/voicechatai/interfaces/`)
- `api/app.py` — FastAPI factory + DI (bootstraps all adapters at startup)
- `api/routes.py` — POST /voice-chat, GET /health
- `api/websocket_routes.py` — GET /ws/transcribe
- `presenters/response.py` — VoiceChatResponse Pydantic schema

## Entry Point & Startup

`main.py` → Uvicorn serves FastAPI app. Auto-finds available port if requested port is busy.

Startup order in `app.py`:
1. WhisperSTT
2. OpenAIEmbedder + ChromaStore + RetrievalService + RAGService
3. OpenAILLM + ElevenLabsTTS + LLMAnswerService + ProcessVoiceChat
4. Register HTTP + WebSocket routes

Boot errors are caught gracefully and stored on `app.state` (returns 503 with error detail).
